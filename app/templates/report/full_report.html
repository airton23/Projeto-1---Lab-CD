1. Base de dados e objetivo

Este projeto analisa pontos, rebotes, assistências, roubos de bola, tocos, faltas pessoais e cestas de três convertidas de Chicago Bulls e Minnesota Timberwolves. O objetivo é comparar valor típico, dispersão, forma das distribuições e qualidade dos dados, sem atribuir causalidade às diferenças.

A origem contém {{ source.original_rows|fmt }} registros, {{ source.original_columns }} colunas e {{ source.original_teams }} times. O recorte das duas equipes tem {{ source.rows|fmt }} registros time-partida, correspondentes a {{ source.games|fmt }} partidas distintas entre {{ source.date_min|fmt }} e {{ source.date_max|fmt }}. Os dois confrontos diretos geram uma linha para cada equipe; isso não é duplicação.

Recorte apresentado: {{ scope_label }}, {{ active_rows|fmt }} registros. Incluem-se jogos contra todos os adversários disponíveis, não apenas confrontos entre as duas equipes. A fonte original e a data de coleta não foram informadas; o período observado não garante cobertura da temporada inteira.
